# Spxdev Plugin Registry

Public host for `index.json`, the Spxdev official plugin marketplace catalog.

This file is generated by `plugin-registry/build-index.mjs` in the main
[`spxdev`](https://github.com/phongdoanthanh/spxdev) repository (private) from
its curated `plugin-registry/plugins.yaml` pointer list, then copied here so it
can be served over plain HTTPS via `raw.githubusercontent.com` without needing
GitHub Pages (which requires a paid plan for a private source repository).

Do not edit `index.json` directly — it is overwritten by CI. To add or change
a catalog entry, edit `plugin-registry/plugins.yaml` in the `spxdev` repo.

Fetch URL used by the Spxdev app:
`https://raw.githubusercontent.com/phongdoanthanh/spxdev-plugin-registry/main/index.json`
